# Vitruvius - UI Redesign PRD ## Project Overview Vitruvius is a decentralized, zero-knowledge encrypted file synchronization platform. The current UI is a functional developer-focused dashboard. The goal is to elevate it into a professional, "privacy-first" application that feels secure, modern, and high-performance. ## Target Audience - Privacy-conscious individuals - Professionals (Legal, Medical, Finance) - Developers and technical users ## Key User Flows 1. **Node Monitoring:** Real-time visibility into the local node's health and identity. 2. **Peer Management:** Discovering, connecting to, and managing a network of trusted devices. 3. **Synchronization Tracking:** High-fidelity visualization of file transfers, including chunk-level progress and verification. 4. **File Management:** Browsing local synced files and version history. 5. **System Metrics:** Monitoring bandwidth (DL/UL), uptime, and system health. ## Design Aesthetic - **Core Concept:** "The Vitruvian Vault" - Balancing the precision of the *Vitruvian Man* with the security of a digital vault. - **Visual Style:** High-tech, dark mode (default), with neon accents (Cyber-Pro). Use of geometric shapes, subtle grid patterns, and clear typography. - **Color Palette:** - Primary Background: Deep Navy/Charcoal (#080b0f) - Surface Colors: Slate Gray variants (#0d1117, #111820) - Accents: Cyber Blue (#00d4ff) for active/primary, Emerald Green (#00ff88) for success, and Crimson (#ff2255) for alerts. - **Typography:** - Display/Headers: Modern Sans-Serif (e.g., Barlow Condensed) - Data/Mono: Clean Monospace (e.g., Share Tech Mono) for IDs and logs. ## Feature Enhancements in the New UI - **Unified Sidebar:** Better navigation between Transfers, Network, and Files. - **Enhanced Transfer Cards:** More detailed visualization of the BLAKE3 chunk verification process. - **Visual Network Map:** A more intuitive way to see peer connections beyond a simple list. - **Refined Event Log:** A cleaner, filtered view of system messages.
